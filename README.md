# 🏨 Hotel Booking Analysis

## 📌 Project Overview
This project focuses on analyzing hotel booking data to understand booking patterns, cancellations, customer preferences, and room pricing trends.

The analysis was performed using Python in Google Colab.

## 🎯 Objectives
- Analyze hotel booking distribution.
- Identify booking cancellation patterns.
- Understand monthly booking trends.
- Study Average Daily Rate (ADR).
- Identify the top 10 countries by customer bookings.

## 🛠️ Tools & Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## 🧹 Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Converted date columns into appropriate formats.
- Prepared the dataset for analysis.

## 📊 Exploratory Data Analysis
The project includes:
1. Hotel Booking Distribution
2. Booking Cancellation Analysis
3. Monthly Booking Trends
4. Average Daily Rate Analysis
5. Top 10 Customer Countries
6. KPI Dashboard

## 📁 Project Files
- `Hotel_Booking_Analysis.ipynb` – Complete Python analysis.
- `cleaned_hotel_bookings.csv` – Cleaned dataset.
- `Visualizations/` – Generated charts and KPI dashboard.

## 📈 Key Outcomes
The analysis provides insights into hotel booking patterns, cancellation rates, customer locations, seasonal trends, and average room pricing.
